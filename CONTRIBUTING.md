# Contributing

Thanks for helping improve FCAI Visualizer! Contributions are welcome, including bug fixes, algorithms, visualizations, translations, and documentation.

## Getting started

1. Fork and clone the repository.
2. Use **Node.js 24.x**.
3. Install dependencies: `npm install`.
4. Start the development server: `npm run dev`.

## Before submitting

- Check existing issues first; discuss larger changes before starting work.
- Follow the project structure and coding conventions in [AGENTS.md](AGENTS.md).
- Keep changes focused and add or update tests when changing logic.
- Run `npm run verify` before opening a pull request.
- Do not commit secrets, `node_modules/`, or build output.

## Commits and pull requests

Open a pull request with a clear summary, the reason for the change, and relevant issue links. Include screenshots for UI changes and mention the checks you ran.

## AI-assisted contributions

AI tools and coding agents may be used. Contributors must review and understand every change, follow [AGENTS.md](AGENTS.md), run the relevant checks, and take responsibility for the submitted work. Do not submit unreviewed or unattended agent-generated changes.
