# FCAI Visualizer

An interactive, free learning platform for algorithms, data structures, and data compression, created to help students understand how operations work step by step.

**Live website:** https://fcai-visualizer-ten.vercel.app/

## Explore
- Interactive algorithm and data-structure visualizers.
- Step-by-step execution and code walkthroughs.
- JavaScript, Python, and C++ examples where supported.
- Sorting, searching, trees, graphs, and compression topics.
- Built-in practice questions.

## Run locally
Requires Node.js 24.x.

```bash
npm install
npm run dev
```

Run all checks before submitting changes:

```bash
npm run verify
```
